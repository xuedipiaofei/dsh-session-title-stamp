会话标题

让侧栏里的每个会话都有一个稳定、可扫读的名字。修改后可随时恢复默认。

实时预览
1027 | 优化 | 降低渲染器内存占用
开启 emoji 后：⚡ 优化
标题格式
分类语言
中文使用「分析 / 实现 / 修复 / 优化…」，英文使用 Analysis / Build / Fix / Optimize…
分类 emoji 前缀
为分类增加视觉标记；默认关闭，开启后会占用少量标题字节。
🔍 分析　🐛 修复　⚡ 优化
日期格式
日期由本地时间计算，不交给模型。
标题模板
支持 {date}、{type}、{topic}，也可用 {YYYYMMDD}、{HHmm} 等。
自动重算 默认开启
回答完成后自动重算
每个完成的 turn 结束后更新标题；fork、子代理和手动固定的标题会跳过。
最小刷新间隔
避免首轮刚生成又再次调用模型。
分钟
消息数冻结
超过该用户消息数后停止自动重算，0 表示不冻结。
条
启动时补刷旧标题
启动后修复仍是兜底标题的 live 会话；会额外调用模型，默认关闭。
▼高级：名称长度、最近消息数、超时与模型路由 （在配置文件中）
修改会写入当前 profile 的插件配置；保存后对新生成的标题生效，已有标题不变。
恢复默认 有未保存的修改
